# Roadmap

Roadmap items are proposals, not promises. Public launch remains gated by the
rights and security conditions in `docs/RIGHTS_STATUS.md`.

## Before any public release

- Obtain written chain-of-title, team, employer/client, and competition
  attestations; approve the final proprietary notice.
- Revoke the exposed legacy provider credential and record rotation completion.
- Add authenticated users and shared gateway/store quotas for live paid calls.
- Define deployment-specific privacy, retention, backup, incident, and access
  policies.
- Produce per-platform hash-verified locks and a reviewed runtime SBOM.
- Perform an independent security assessment and deployment accessibility test.

## Candidate product work

- Make history opt-in and allow users to clear the full anonymous session.
- Add measured-data import with explicit units, source timestamps, and provenance.
- Add operator-configurable scoring rubrics with calibration/evaluation datasets.
- Add audit-friendly exports that distinguish observation, inference, and action.
- Add account-backed authorization only after a concrete deployment requires it.
- Evaluate more locales with native reviewers and bidirectional UI testing.

No production deployment, certification workflow, quantified savings forecast,
or autonomous control action is currently planned as an implemented feature.
