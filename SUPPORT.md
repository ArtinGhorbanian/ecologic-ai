# Support

EcoLogic is a private preview, not a supported production service.

- Reproducible product defects: use the bug report template with synthetic data.
- Bounded product proposals: use the feature request template.
- Vulnerabilities or credentials: follow `SECURITY.md` and report privately.
- Data-handling questions: read `PRIVACY.md` before enabling live mode.
- Ownership, attribution, or publication questions: follow
  `docs/RIGHTS_STATUS.md` and keep the repository private.

No response-time commitment, uptime promise, professional environmental advice,
or deployment support agreement is provided by this repository.
